# Security Policy

Security Policy

Supported Versions

Security fixes are currently focused on the latest release of Refract.

Reporting a vulnerability

If you discover a security vulnerability in Refract, please report it privately through GitHub.

[Report a Vulnerability](https://github.com/6bledd/refract/security/advisories/new)

Please include:

* A description of the vulnerability
* Steps to reproduce the issue
* The potential security impact
* Screenshots or logs if applicable
* The affected version of Refract

Please avoid publicly disclosing security vulnerabilities before they have been investigated.

Security Practices

Refract is an open-source music player developed with AI assistance and personally tested before each release.

The project uses automated security analysis to help identify potential vulnerabilities.

Security reports are welcome and appreciated. I will investigate reported issues as time permits and work toward fixes where possible.

Thank you for helping keep Refract safe.
